# 跨主題的教訓

> 踩過不只一次、換個地方還會再踩的事；一條一句，細節連到出處頁。
> 原始資料：CLAUDE.md 各段的「踩過的坑」「教訓」。這一頁是新寫的，不是從 CLAUDE.md 某一段切出來。
> 最後更新：2026-10-29

## 現在怎麼運作

動手前掃一遍這份清單；做完事如果又學到一條，加在對的分類底下（一句話＋出處頁）。

### 資料
- **兩個來源並排呈現時，先問它們是不是同一天的**——沒有一致性檢查，就等於預設永遠同步，而降級機制保證了遲早不同步（ETF 收盤價與當日漲跌差一天、方向相反）。→ [ETF 當日漲跌](main/etf-daily-change.md)
- **防呆保住了資料、卻沒讓異常被看見＝靜默凍結**：「抓不到就沿用舊值」一定要配一個「過期」標記（外資淨空單連 6 天顯示舊值）。→ [市場溫度計](main/macro-thermometer.md)
- **兩家媒體一致不等於官方口徑**；有官方落檔就讀官方，不要手動填彙整站的數字。→ [新聞規則](ops/news-rules.md)、[市場溫度計](main/macro-thermometer.md)
- **官方也會事後修正**：只補缺日的落檔會凍住早期快照，最新一天要每輪重抓。→ [市場溫度計](main/macro-thermometer.md)
- **說「沒有資料」之前，先 grep 專案裡有沒有人已經在抓**（除權息參考價其實早就有）；下結論前先查既有能力（`products.json`、舊管線）。→ [ETF 持股資料](main/etf-holdings.md)
- **兩種還原疊在一起時，先問這一跳是不是已經換算過了**（頁面價格的口徑連續化＋官方除權息倍數＝還原兩次）。→ [新飆股前瞻記錄](lab/boom-live.md)
- **任何「日期對不上交易日就 continue」都可能靜默丟資料**（颱風假的除權息整筆略過）。→ [逐筆交易](lab/trades.md)
- **用 Unicode 區段或字型當判準前，先確認區段裡的記號是不是別的語言也在用**（日文假名區段含「・」「ー」，一刀殺掉台灣標題）；外語判準用該語言獨有的字。→ [復華新聞與社群](main/fund-news.md)
- **排程（GitHub cron）是盡力而為**，會遲到 1～3 小時、會整班消失；準時要靠 Routine，cron 只當兜底。→ [每日時點](ops/schedule.md)

### 研究與回測
- **組的大小由結果決定時，「每組先平均再平均」一定偏**（狀態型訊號每一段一樣重，放大了很快反轉的短段）。→ [訊號總覽（二）](lab/signals-versions.md)
- **重算只能驗證「照定義算對了」，驗不出定義本身錯了**；要拿「今天看到訊號的人實際面對什麼」去核對定義。→ [訊號總覽（二）](lab/signals-versions.md)
- **固定的公布時間差會在延後公布時偷看未來**（2025 停擺：9 月失業率早用 31 個交易日），截斷重算抓不到（它用同一套假設）；補缺月的值要等補值用到的最後一個月公布才算拿得到。→ [美股景氣頁](lab/heat-us.md)
- **網頁每天更新時，最新一天是「還沒過完的那一週／那個月」**：以週、月取樣的訊號要等那一期過完才算（週訊號曾經週中先出現、週五又不見，約四次一次）。→ [訊號總覽](lab/signals.md)
- **少數樣本的中位數拿去和大量樣本的中位數比，一定偏**；量逐年樣本外用平均或 0／1。→ [訊號總覽（二）](lab/signals-versions.md)
- **後一段研究改掉了前一段決定的前提，要回頭問使用者那個決定還算不算數**，不要照舊套用。→ [訊號總覽（二）](lab/signals-versions.md)
- **持有期差一天，結論可以正負顛倒**：任何策略結論先做持有期 1～10 日全掃描，探索腳本和正式回測用同一個出場定義。→ [籌碼雷達的訊號與第一代策略](lab/chip-strategy.md)
- **規格先寫、先 commit，才算結果；看過結果才改的，要照實寫出來**；不為了結果好看放寬門檻。→ [使用者偏好](user.md)

### 頁面與程式
- **防呆擋下錯值之後，讀者看到什麼也要驗**（「⚠ 基準 2026-09-20」印了一個週日，看起來比錯數字還糟）。→ [ETF 當日漲跌](main/etf-daily-change.md)
- **版面驗證看「真的看得到」，不看 class**（`offsetParent`／截圖）；改版後確認舊實作真的拿掉，別讓測試守著死碼。→ [ETF 詳情區](main/etf-detail.md)
- **新增 CSS class 前先查有沒有撞名**；幾支 JS 串成同一個 `<script>` 時不能有同名函式或頂層 const。→ [籌碼雷達介面](lab/chip-ui.md)、[景氣頁視覺化](lab/heat-viz.md)
- **把別的模組的 HTML 搬進一頁時，樣式要一起帶**。→ [導覽與入口](lab/nav.md)
- **寫進 `GITHUB_OUTPUT` 的指令，stdout 只能有那個值**（多一行說明就讓整班 workflow 失敗）。→ [行事曆與休市表](main/calendar.md)
- **探針要印上下文片段，不要只印次數或鍵名**，才能一輪就看懂結構。→ [即將登場與新 ETF 發現](main/etf-upcoming.md)
- **`.ping/lab` 第一行只能寫模式**（寫成「模式 時間戳」會落到預設的完整回補）。→ [總經策略](lab/expert.md)

### 上線與部署
- **修法要進 main 才算數**：寫進文件、推到分支都不等於上線；改 workflow 檔要確認 main 上真的有。→ [Actions 額度](ops/ci-budget.md)、[ETF 當日漲跌](main/etf-daily-change.md)
- **「內容在 main」不等於「線上已部署」**；線上看到舊的，先讀部署步驟的日誌，不要從抓取端查起。→ [部署](ops/deploy.md)
- **push 觸發的 workflow 用的是「被推分支」上的 workflow 檔**：分支太舊，新加的金鑰、步驟就不生效（要排程搬家）。→ [排程](ops/routines.md)
- **防線不可硬到什麼都沒更新**：數字核對不擋發佈，結果上板、見紅就修。→ [全部更新](ops/daily-update.md)
- **commit 前 `git add` 寫明路徑**，不用 `-A`。→ [容器的限制](env/container.md)
