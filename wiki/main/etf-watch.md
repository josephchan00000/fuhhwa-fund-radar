### 欄序與每一欄從哪來

欄序＝最新收盤價／**當日漲跌**／過去一週／過去一月／最近一次配息／換算年化配息率／收益分配頻率／**規模／成立日期（靜態資料移到最右）**。

| 欄 | 來源與算法 |
|---|---|
| 最新收盤價 | 原本＝etfinfo 市價；2026-09-21 起以官方全市場當日收盤表為準、上櫃檔不收 etfinfo 市價（見 [當日漲跌](etf-daily-change.md)）。上櫃 etfinfo 未收錄的檔由報酬序列末值回填 |
| 當日漲跌 | 收盤序列、官方當日表、etfinfo 前收三個來源，詳見 [當日漲跌](etf-daily-change.md)。除息日以「除息參考價＝前收 − 每單位配息」為基準並標【除息】——否則整段配息會被算成跌幅 |
| 過去一週／一月 | 多來源自算，見下一小節；總報酬口徑，儀表板報酬格標「＋息X」 |
| 最近一次配息 | 最近一次「實際」除息金額 |
| 換算年化配息率 | 見下方「配息」 |
| 收益分配頻率、規模 | etfinfo.tw（Tier B） |
| 成立日期 | `WATCHLIST` 靜態值 |

**雙資料來源，各自獨立降級**：規模／年化配息率／配息頻率 ← etfinfo.tw（Tier B）；過去一週／一月報酬 ← 多來源自算。
來源 etfinfo.tw 屬 Tier B，正式對外前以各投信官網核對。

### 過去一週／一月報酬

- `_fetch_returns`：stooq → Yahoo → FinMind → `arm/connectors/twse.fetch_month`，依序取第一個歷史夠密者；`ret_src` 記每檔實際用了哪個源供追查。
- 以最新交易日收盤對回推 7／30 日曆日前最後交易日計算，並有「基準日須接近目標日」防呆，避免稀疏序列算出錯值。
- **總報酬口徑**：Yahoo 抓取帶 `events=div`，區間內除息加回再算。
- 債券型（`_BOND_CODES`，收盤天然重複）把 `_is_degenerate` 髒序列門檻放寬至 15%。
- 序列另有兩道入口處理（濾掉不可能的交易日、錨定官方當日收盤），見 [當日漲跌](etf-daily-change.md)。

### 配息

- **配息殖利率一律用年化配息率**＝最近一次「實際」配息金額 ÷ 最新市價 × 配息頻率次數（月配×12／季配×4／半年配×2／年配×1），
  不是 trailingYield 近12月回溯值。
- 上櫃兩檔 etfinfo 未收錄 → 規模／首配用 WebSearch 查證種子（`SEED_PERF` 含 `last_div`），年化配息率以配息×次數÷序列收盤自算。
- **當月預估配息**（etfinfo 只揭露已實際除息者、抓不到投信預告）：依序 MOPS（`arm/connectors/mops.etf_distributions`，端點多變、常抓不到）
  → **`arm/etfwatch.ANNOUNCED_EST` 人工維護清單**（投信官方已公告之首配／當期預估，除息日未到）。
  取本月未到期者 → 配息欄加註「預估 X*」橘標，過月自動失效。*＝投信公告非正式配息金額，實際以除息公告為準。
  投信於配息月已公告該月預計配息金額時（etfinfo 配息表中除息日在本月且未到期／標記預估者），同樣標「預估 X*」。

### 資料層與合併

- 落檔 `data/etf_watch.json`：`scripts/fetch_etf_watch.py` 逐檔「欄位級合併」，fallback 鏈為
  **本次 etfinfo 新值 → 既有落檔值 → 內建 `SEED_PERF` 週報底稿**（成立日一律取 WATCHLIST 靜態值）。
- 報酬數據標 `perf_asof` 基準日、規模／殖利率標 `as_of` 抓取日，儀表板分別備註（沿用最近可得值時使用者已同意）。
- 抓取只在正式區 CI 跑；容器裡跑 `fetch_etf_watch.py` 會空轉逾時，見 [容器的限制](../env/container.md)。

## 不能改的規則

- `data/etf_watch.json` **必須入庫**當 fallback（`.gitignore` 的 `data/*` 有 `!data/etf_watch.json` 例外）。
- 欄位級 fallback 用「值是否為 None」判斷，**不可用 `dict.get(key, default)`**；用 `arm/etfwatch._pick()`。
- 配息殖利率一律用年化配息率，不用 trailingYield。
- **投信新公告配息時，把 `{code: {amount, ex_date}}` 補進 `ANNOUNCED_EST`**（來源：各投信官網／經濟日報等；除息後 etfinfo 會接手實際值）。
  例：00991A 首配 0.77（除息 7/21）、0056 Q3 擬配 1.35。
- 當日漲跌抓不到就沿用既有值，絕不洗成空白（顯示前另有同日檢查，見 [當日漲跌](etf-daily-change.md)）。

## 踩過的坑

- **落檔沒入庫 → 整片 null**：`data/etf_watch.json` 曾被 `.gitignore` 的 `data/*` 擋掉沒入庫 → CI 從零抓、etfinfo 缺欄 → 成立日期／週月報酬整片變 null。
  修法：`.gitignore` 加 `!data/etf_watch.json` 例外。
- **`dict.get` 把資料洗空**：CI 曾把欄位寫成顯式 `null`，`get(key, default)` 會回傳那個 null 而非 default。修法：`arm/etfwatch._pick()`。
- **除息被算成報酬下跌（2026-07-22）**：7/16 除息 4.75 的 006208，一週報酬比同指數 0050 多跌整整一個股息。修法：改總報酬口徑（`events=div`、除息加回）。
- **債券型報酬整片空**：00986D 收盤天然重複，全源被 `_is_degenerate` 誤判髒。修法：`_BOND_CODES` 放寬門檻至 15%。
