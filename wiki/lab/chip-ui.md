## 現在怎麼運作

### 分頁（版面 v4，整頁以「策略選股」為主軸）

2026-10-22 起「機會」「策略」搬到頂欄「策略」的個股策略底下，改叫「這一期」「規則與成績」，內容不變；個股頁剩 個股｜籌碼｜指數（見[策略頁：總經策略／個股策略](strategy-pages.md)）。

- 頁首一句網頁目的（`.purp`）；每個分頁最上面一句話說這頁回答什麼（`.intro`）。
- 機會（`vOpp`）：摘要（推薦策略 N 條、待買進、持有中、全部照做約占資金；`ADV.opp`）＋時間表（`ADV.cal`，一列一件事）→ 每條推薦策略一張卡（`o-{k}`：做法／隱含獲利／現在（待買進、持有中）／下一批）→ 避開清單。C 級不上機會頁。
- 策略（`vSt`）：比較表（推薦順序與理由、平均、賺錢比例、同期大盤、年化；手機把同期大盤放在平均下面）→ 說明卡（`stCard`：結論／怎麼做／過去成績／風險；有長歷史的放逐年報酬表＋「1 元變多少」策略對大盤曲線）→ 部位（`posSec`）。
- 推薦順序（`advice.rank`）：只排 ★ 好策略、● 可參考，★ 在前、同級依逐筆賺錢比例；理由＝逐筆成績一句（`advice.rank_why`）。
- 個股：表上「策略選到的（N）」篩選、股名下策略標籤（`PK`＝`ADV.picks`，只含 A、B 級）；不在 ETF 持股範圍的股票列在表上方一行；個股卡最上面「策略」段（`stCardSec`）。
- 籌碼（`vChip`）：原今日頁的重點／買賣／新建倉／風險＋投信動向（`issSec`，原投信頁）＋今日訊號（`sigTodaySec`：一句結論＋各訊號今天的股票）。
- 指數：時程、臺灣50 預測、高股息預估、被動換股、其他。
- 後台（`vBo`，`VIEWS.bo`）：今天的驗證（事件、06:35 推播會帶的兩行）→ 前瞻紀錄（起算日、已出場／A 級門檻、平均報酬、同期大盤、比同一批股票、持有中、過去最差）→ 事件紀錄 → 評級規則、評級總表、各策略評級依據、全部策略總表 → 訊號成績 → 換股研究（臺灣50、高股息研究、買盤大小、提前卡位）→ 每日更新時程。
- v3 的元件（v4 保留內容、只搬位置）：驗證頁（`vVal`，`VIEWS.val`）＝評級規則 → 評級總表（`val-grade`）→ 各策略評級依據（`val-{k}`：評級、評級依據、展開細節）→ 全部策略總表（`val-bt3`）；
  訊號（`vSig`）＝結論 `sigConcl`＋一覽表（持有 5／20 天實際平均、賺錢比例、同期大盤、能不能照做 `sigVerdict`；共識加碼連到 B 級策略 `SIGST`；手機 20 天與結論在每列下面一行 `tr.sgw`），舊「勝率」（＝贏大盤比例）不再出現；
  行事曆 `calSec`（`ADV.cal`：今天之後的買進／賣出／換股／調整，依日期、同天開盤在前；只列 A、B 級；已買進的部位只出現在賣出日；名單還沒產生的列「名單 X/X 收盤產生」）、避開 `avoidSec`、策略一覽 `bookSec`（`ADV.book`：每次／每檔平均與中位、賺錢比例、最差、同期大盤、年化與大盤年化）。

## 踩過的坑

- CSS 撞名：事件卡已用 `.ev`，投信卡項目首版也叫 `.ev` → 手機上一格格重疊的框。
- 投信事件少算：`iev` 上限 40 → 300，40 筆會少算（安聯 5 日就有 212 筆）。
- 海外代號撐寬手機頁：投信卡的海外代號（`BMNR US` 等）之間沒有斷行點，手機把整頁撐寬到 594px → `.eit` 改 inline-block。
- 跳不到錨點：從個股卡的連結跳分頁時用 `history.back()` 關卡片，瀏覽器會還原捲動位置 → 改用 `replaceState`＋`hideStock()`。
- x9s.json 過渡期：push 觸發的 daily.yml 用「被推分支」上的 workflow 檔，排程會話分支若分岔自本改版合併前，那一輪不會 add `x9s.json`，線上序列檔停在前一班 main workflow（cron／dispatch）產的版本（照日期註記顯示）；下一班 cron／dispatch 自然補上，根治＝合併後做一次「排程搬家」。
