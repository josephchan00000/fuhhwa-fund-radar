# W4　大盤時機：什麼時候名單比較準（規劃，事前寫定）

這份文件在看任何 W4 結果之前寫定並 commit。之後要改任何一條＝新版本，日期與原因寫在第 8 節。

## 0. 為什麼做

- 2026-10-16 使用者看完 W3 結果，選了「用價格強度縮短名單」與「加入大盤時機」。
- W3 看到名單的命中率跟大盤很有關係：一年內翻倍，2020 年 27.8%、2021 年 13.6%、2022 年 16.5%。
- **問題**：每週收盤時看得到的大盤狀態，能不能事先分出「名單比較準」和「比較不準」的時候？
- 小型股（40 億以下）需要 FinMind 完整資料，使用者沒有，這次不做。

## 1. 命中率與單位

- 同 W3：每週最後一個交易日 × 合併名單 S9 上的股票。主要目標＝一年內翻倍；另列 3 個月 +50%、一年 3 倍。
- 也報「價格強度子名單」（RS ≥ 90 或相對強勢前 10%，W3 結果出來後使用者選的）與全部合格股票的命中率。
- 同一週的股票共用同一個大盤狀態，而且狀態一連持續好幾週，真正獨立的樣本很少。報告會寫出每種狀態出現過幾段。

## 2. 大盤狀態（全部事前列出，之後不加）

每週收盤時算，只用當天以前的資料。加權指數＝價格指數。

| # | 變數 | 狀態 |
| --- | --- | --- |
| M1 | 加權指數在 200 日線之上 | 是／否 |
| M2 | 加權指數 50 日線 > 200 日線 | 是／否 |
| M3 | 加權指數離 52 週高點 | 5% 以內／5～15%／15% 以上 |
| M4 | 合格股票站上 200 日線的比例 | 40% 以下／40～60%／60% 以上 |
| M5 | 合格股票通過趨勢樣板的比例，比 4 週前 | 增加／沒有增加 |
| M6 | 52 週新高家數 − 新低家數（合格股票、收盤價） | > 0／≤ 0 |
| M7 | 名單（S9）檔數，比過去 52 週中位數 | 較多／不較多 |
| M8 | 加權指數近 6 個月（126 日）報酬 | > 0／≤ 0 |
| M9 | 加權指數 20 日波動，比過去 252 日中位數 | 較高／不較高 |

## 3. 怎麼選（只用 2014–2019）

- 每個變數：各狀態下 S9 的一年翻倍命中率、週數、出現段數。
- **差距**＝命中率最高的狀態 ÷ 最低的狀態（只比 2014–2019 有 ≥ 26 週的狀態）。
- **穩定**：兩個子期間（2014–16、2017–19）裡，同一個狀態最高、同一個狀態最低，差距都 ≥ 1.3，而且兩個狀態在兩個子期間都各有 ≥ 13 週。
- 選穩定的變數裡、2014–2019 差距最大的一個。沒有變數穩定 → 結論是「看不出穩定的大盤時機」，不做下一步。
- 只選一個變數、不組合：2014–2019 只有幾次大盤循環，組合很容易是巧合。

## 4. 驗證（2020–2022；判定先寫死）

- 選中的變數，同一組最高、最低狀態在 2020–2022：
  1. 差距 ≥ 1.3，而且方向相同；
  2. 兩個狀態各有 ≥ 13 週。
- 過關 → 頁面寫目前的大盤狀態，以及過去這種狀態下名單的命中率（2014–2022），並列另一個狀態的命中率對照。
- 不過關 → 頁面不寫大盤時機。
- 2023 年起只列數字，不參與判定。
- 不管過不過關，都報逐年表：每年 S9 命中率、全部股票命中率、加權指數漲跌。

## 5. 頁面

- 合併後的「飆股」段：
  - 預設先列價格強度子名單（RS ≥ 90 或相對強勢前 10%），其餘收起來。
  - 子名單寫過去命中率，並註明「這個條件是看過 2020–2022 結果後才選的」。
- 大盤時機過關才多一行：「目前大盤：○○；過去這種時候名單 X% 一年內翻倍（另一種時候 Y%）」。
- 交叉比對標籤（7 族）照 W3 的結論只當參考，寫明「過去沒有明顯提高命中率」。
- 後台加前瞻紀錄：價格強度子名單與 S9 的命中率追蹤（一年翻倍要等一年，先看 3 個月 +50%）。

## 7. 限制

- 大盤狀態一連持續好幾週，2014–2022 年只有幾次完整循環，結論的把握遠低於股票層的比較。
- 一年內翻倍在大跌之後特別容易發生（全部股票一起反彈），所以「比較準的時候」可能只是「大家都漲的時候」。報告同時列全部股票的命中率，讓兩者分得開。
- 名單只收月底市值 ≥ 40 億的股票。
