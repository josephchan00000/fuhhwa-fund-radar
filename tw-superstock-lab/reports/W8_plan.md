# W8　飆股「抱到出場條件才賣」：新目標也試一次出場法（事前寫定）

使用者（2026-10-23）：「你飆股應該是如果沒有滿足出場條件就一直持有吧？」

現行（W7 回測、飆股前瞻記錄）是**固定抱 60 個交易日就賣**，中間不看漲跌、不停損。
舊規則（現行頁面 R1）在 `../docs/lab_core70_plan.md` 第 11.3 節試過幾種「抱到出場條件」（最多抱 250 天）：
跌破 50／20 日線 16.5%／15.7%、從 60 日高點回落 15／20／30% 12.7／19.3／20.8%，固定 60 天 20.0%（2014–2026）——沒有一種穩定比較好。
新目標（W7 逐年找規則）還沒試過。這份文件在跑任何結果之前 commit；規格 `../arm/lab/sxexitspec.py` VER 1。

## 1. 出場法（收盤判斷、隔天開盤賣；一價到底跌停延後；除了 X0 都沒有時間上限，資料最後一天收盤結算）

| | 出場條件 | 說明 |
| --- | --- | --- |
| X0 | 固定抱 60 個交易日 | W7 原本的做法；數字必須和 W7 完全相同（檢查） |
| X1 | 收盤跌破 50 日均線 | 趨勢派最常用的 |
| X2 | 收盤跌破 20 日均線 | X1 的鄰近 |
| X3 | 收盤比買進以後的最高收盤低 20% | 追蹤停利 |
| X4 | 同上，低 30% | X3 的鄰近 |
| X5 | 收盤比買進價低 8%，或跌破 50 日均線 | 《超級績效》的停損＋趨勢出場 |
| X6 | 收盤比買進價低 20%，或比買進以後最高收盤低 30% | 長線 S5 式（沒有 250 天上限） |

「買進以後的最高收盤」、買進價都用含息還原價（引擎的價格）。

## 2. 不改的

訊號、買進、資金照 W7（`../arm/lab/superfixspec.py` VER 1）：R60 主要、A 對照；每年的規則＝`W7_results.json` 那一年的那一折（不重找）；
每週最後一個交易日訊號、隔天開盤買、每檔 12.5%、同一天依 RS 高到低；2019-01-02 起連續跑到資料最後一天；成本照引擎預設。

## 3. 判定（只看 R60）

一種出場法「比固定 60 天好」＝
1. 前後兩半（2019–2022、2023 起）的年化都比 X0 高；
2. 整段最大回落沒有比 X0 深超過 5 個百分點。

X1／X2、X3／X4 是鄰近參數：同一組裡方向不一樣時寫「對參數敏感」。A 只描述；贏不贏大盤只列出。
