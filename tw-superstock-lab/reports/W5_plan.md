# W5　《超級績效》VCP 參數查核：命中率低是不是參數設錯（事前寫定）

使用者（2026-10-16）：「我還是不相信超級績效選出來的命中率會低欸 你是不是參數設錯」

這份文件在跑任何新結果之前 commit。第 1 節是之前已經跑過的數字；第 2 節的查核只看型態結構，沒有看之後的漲跌。

## 1. 之前的數字（W1、W3）

一年內翻倍的比例（股票週，W1_watch.md）：

| | 2014–2019 | 2020–2022 |
| --- | --- | --- |
| VCP＋樣板（S5） | 8.2% | 13.9% |
| 趨勢樣板（S2） | 9.2% | 17.6% |
| 合併名單（S9） | 11.5% | 18.7% |
| 全部合格股票 | 5.8% | 13.2% |

頁面上「VCP 比名單低」是和名單 S9 比。和全部股票比是 1.41 倍、1.05 倍；和樣板股比是 0.89 倍、0.79 倍。
所以真正要回答的是：**VCP 有沒有讓樣板股更容易翻倍**。

## 2. 查核：程式抓到的 VCP 和書上描述的差在哪

### 2.1 書上怎麼說

原書逐字沒有查到，以下是二手整理（LuxAlgo、TradingView 指標說明、finermarketpoints、deepvue）一致的部分：

- 每一段回檔比前一段小（常見 2～4 段，最多 5～6 段）；
- 低點逐段墊高，價格守在高點附近；
- 回檔時量縮，最後一段最明顯；
- 帶量突破樞紐（最後一段的高點）才進場；
- 股票要在第二階段（趨勢樣板）。

來源：[LuxAlgo](https://www.luxalgo.com/library/concept/volatility-contraction-pattern/)、
[TradingView 指標說明](https://www.tradingview.com/script/J1tqSCqR-Volatility-Contraction-Pattern/)、
[finermarketpoints 檢查表](https://www.finermarketpoints.com/post/vcp-criteria-complete-checklist)、
[deepvue](https://deepvue.com/screener/volatility-contraction-pattern/)、
[sharpely](https://sharpely.in/blogs/volatility-contraction-pattern-vcp-rule-based-screener-built-high-quality/)。

### 2.2 現行程式（V2）抽樣與統計

對象：2014–2022 年「VCP 成立＋樣板全過」的 2,168 個股票日（`scripts` 外的診斷，只算型態）。

| 項目 | 結果 |
| --- | --- |
| 低點逐段墊高 | 只有 35% |
| 高點逐段降低 | 51% |
| 樞紐 ÷ 基底高點 | 中位數 0.935，四分之一低於 0.904 |
| 最後一段低點在基底上半部 | 只有 15% |

另外三點：

1. 「每段 < 前一段 × 1.1」容許後一段比前一段深。例：2474 在 2014-03-31，兩段是 7.0%、7.5%，第二段低點更低。
2. 判定當天收盤可以已經在樞紐之上，「成形」裡混進已經突破的日子。例：3454 在 2019-01-15，收盤 83.96、樞紐 80.62。
   這檔的三段是 18%、13%、9%，高點從 92.9 降到 80.6，低點從 75.8 降到 72.5——比較像下跌中的收斂。
3. 基底至少 30 個交易日（SPEC §5.3）。樣板全過、但離 260 日高點不到 30 日的股票日有 160,347 個，全部不會被判成 VCP。
   強勢股常在高點附近整理 3～5 週，這些都被排除。

用含息還原價畫型態（書用實際股價），除息日附近的段落深度可能差幾個百分點。只記錄，不改。

## 3. 照書修正的版本（寫定，不依結果調）

| 版本 | 內容 | 用途 |
| --- | --- | --- |
| V2 | 現行 | 對照 |
| **V3** | V2 再加下面四條 | **主規格** |
| V3s | V3，但基底至少 15 日（3 週） | 另外判定 |
| V2＋① …… V2＋④ | V2 每次只加一條 | 只看哪一條有影響，不拿來下結論 |

V3 加的四條：

1. 每段嚴格比前一段小（倍數上限由 1.1 改成 1.0）；
2. 低點逐段墊高（後一段低點 > 前一段低點）；
3. 最後一段低點在基底上半部：≥ 基底最低 ＋ 0.5 ×（基底高點 − 基底最低）。基底最低＝各段低點的最小值，0.5 取自歐尼爾杯柄的「柄在上半部」；
4. 成形只算還沒突破：樞紐 × 0.9 ≤ 收盤 ≤ 樞紐。

其他條件不動：轉折門檻 max(3%, 1.5 × ATR14 ÷ 收盤)、2～6 段、第一段 ≤ 35%、最後一段 ≤ 10%、量縮 ≤ 0.7、趨勢樣板 8 條。

## 4. 比法

- **樣本**：合格股票（同 W1／W3，含最近月底市值 ≥ 40 億）。週資料用 W3 快取的 711 個週末交易日。
- **標籤**
  - B：之後 250 個交易日內最高價 ≥ 收盤 × 2。這是使用者在 W3 選定的目標。
  - A：之後 60 個交易日內最高價 ≥ 收盤 × 1.5。
  - H（交易命中）：之後 120 個交易日內先漲到 +20%、才碰到 −8%。同一天兩個都碰到算失敗；120 日都沒碰到也算失敗，另列比例。−8% 是書上的停損。
- **狀態（每週）**：該週最後交易日 VCP 成立，且樣板全過。另列「新出現」（上週不成立）。
  - 比較對象：全部合格股票、樣板股、名單 S9。
- **突破（事件）**：同時滿足下列條件，標籤從突破日收盤起算。
  - 前一天 VCP 成立；
  - 當天收盤 > 樞紐，且 ≤ 樞紐 × 1.05；
  - 當天量 ≥ 前一天的 50 日均量 × 1.5；
  - 樣板全過、合格。
  - 比較對象：樣板股的一般突破（收盤 > 前 20 日最高價，量的條件相同）、全部樣板股日。
- **期間**：2014–2019（IS）、2020–2022（VAL）用來判定；2023 年起只列參考（保留期已經用過）。
- **信賴區間**：Wilson 95%。股票週之間有自相關，區間會偏窄，只當參考。

## 5. 判定（寫定）

- **樣本下限**：狀態每段 ≥ 50 個股票週、突破每段 ≥ 30 次。不足就標「樣本不足」，不判定。
- **(a) 偏離書的地方是不是原因**：V3 狀態的 B 命中率在 IS 和 VAL 都高於 V2 → 「偏離確實拉低命中率」；否則 → 「不是原因」。
- **(b) 照書的 VCP 有沒有加分**：以下兩條都成立 → 「有加分」；否則 → 「沒有」。
  - V3 狀態的 B 命中率在 IS、VAL 都高於樣板股；
  - V3 突破的 B 命中率在 IS、VAL 都高於樣板一般突破。
- V3s 用同樣的規則判定、另外寫。不取 V3、V3s 較好的那個當結論，主規格是 V3。
- (a)、(b) 都成立 → 提議把名單裡的「VCP＋樣板」換成 V3（使用者同意才改頁面與每日名單）。
- 只有 (a) 成立 → 改頁面說法：照書修正後比較準，但沒有比樣板股高。
- H、A 標籤只列出、不參與判定，避免多重比較挑結果。

## 6. 限制

- 書中規則是二手整理；門檻數字（上半部 0.5、3 週）是我依二手描述與歐尼爾杯柄規則定的。
- 樣本可能很小：V2 每週約 1 檔，V3 只會更少。
- 標籤用含息還原價，與 W1／W3 相同。
