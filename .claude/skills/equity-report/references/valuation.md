# 估值怎麼做（規格 `arm/lab/eqspec.py` VER 1，不能改；要改＝VER＋1 並先問使用者）

資料包 `val` 已經算好：`method`、`f12m`（未來 12 個月 EPS 與來源）、`band`（本公司近 5 年每月本益比、淨值比的分位數）、
`peer_pe`／`peer_pb`（同業現在的分位數）、`range`（可用倍數 lo～hi 與預設 dflt）、`tp_dflt`、`rating_dflt`、`scen_dflt`。

1. **方法不能選**：照 `val.method`（本益比法、淨值比法、暫不評等）。
2. **倍數可以選**，但只能在 `range.lo`～`range.hi` 之間。預設＝`range.dflt`（本公司中位數與同業中位數的平均）。
   不用預設時，開頭寫 `mult_why`：根據什麼（成長率比歷史高或低、獲利結構改變、同業重新定價……），用資料包的數字講。
   不要為了讓評等變成「買進」而挑倍數；倍數先決定，評等跟著上檔空間走。
3. **目標價**＝`round_tp(base × mult)`：台股 <50 元取到 0.5、<100 元取到 1、<500 元取到 5、<1,000 元取到 10、以上取到 50。
   用 `python3 -c "from arm.lab import eqspec as S; print(S.round_tp(23.79*25))"` 算。
4. **評等**＝上檔空間（目標價 ÷ 資料日收盤 − 1）：≥ +15% 買進、≤ −10% 減碼、中間中立。
5. **情境**：頁面依 `range.lo`／`range.hi` 與 EPS ±15% 自動算；文字寫每個情境要發生什麼事（營收、毛利率、產業）。
6. **法人共識**只當對照：寫我們的目標價比共識高或低多少（頁面算好的數字），差在哪個假設。
7. **同業**：資料包照規則選 6 家。產業鏈把不同業務放在一起時可以換最多 3 家（`--peers` 重跑資料包），開頭寫 `peers_why`。
