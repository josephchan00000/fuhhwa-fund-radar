# 個股報告的格式（`reports/eq/{tw|us}/{代號}/{報告日}.md`）

圖、表、評等框、目錄、方法、免責聲明由頁面程式放；你只寫下面這些文字。正文（不含資料來源）6,000～14,000 字。

## 開頭欄位（`---` 包住，一行一個，值是 JSON 就照 JSON 寫）

```
---
code: "4958"
name: 臻鼎-KY
mk: tw
made: 2026-10-30            # 報告日（和資料包檔名同一天）
asof: 2026-10-29            # 資料包的 asof（最新收盤日）
title: 一句話的論點，40 字以內（不是事件標題）
rating: 減碼                # 照資料包算：上檔 ≥ 15% 買進、≤ −10% 減碼、中間中立
tp: 410                     # 基數（val.base：共識法＝未來 12 個月 EPS、近四季法＝近四季 EPS）× mult，照 eqspec.round_tp 進位
method: pe                  # 照資料包 val.method
mult: 17.3                  # 在 val.range 的 lo～hi 之間（預設 val.range.dflt）
mult_why: 不用預設倍數時寫原因（至少 20 字）
peers: ["3037", "8046", "2368", "3044", "2313", "6191"]   # 和資料包 peers 一樣
peers_why: 換過同業才寫
ind: tw-L000                # 產業報告代號
---
```

## 段落（`## 段名`，順序固定，一個都不能少）

1. `## 重點`：3～4 條，每條 `■ **一句結論。** 3～5 句說明，數字先講。`
2. `## 投資論點`：3 個 `### 論點名稱`，每個 250 字以上：事實（數字）→ 為什麼會這樣（因果）→ 對營收／獲利／估值的影響。
3. `## 風險`：4～6 條 `- **風險名稱**：會怎樣影響（往哪個方向、影響哪個數字）；觀察：看什麼數字或事件、什麼時候。`
4. `## 公司概況`：做什麼、主要產品與營收結構（官方數字附連結）、主要客戶、生產據點、經營層、最近一次法說會說了什麼。
5. `## 產業與競爭`：產業報告的重點摘要（3～5 句）＋本公司在產業鏈的位置、主要競爭者、比別人好或差在哪。
6. `## 財務分析`：營收（季、月）、毛利率與費用、獲利、現金流、資產負債。只寫圖表看不出的「為什麼」，不要把表格念一遍。
7. `## 同業比較`：本公司在同業裡的位置（成長、獲利能力、估值），估值高或低的理由。
8. `## 估值`：用哪一把尺（共識法或近四季法）、為什麼是這個倍數（和同業比；本公司歷史只當參考）、目標價怎麼來、和法人共識差在哪、三個情境各要發生什麼事。
9. `## 催化劑與籌碼`：至少 3 條 `- YYYY-MM-DD：事件（為什麼重要）`（日期在報告日之後；不確定的日期寫法定期限或公司公告的日期），
   再寫法人、ETF、融資的變化代表什麼。
10. `## 為什麼被選上`：哪一條策略、哪幾個條件、當時的數字；策略看的時間（例如 60 個交易日）和評等看的 12 個月不同，各講各的。
11. `## 資料來源`：每條 `- [標題](網址)（YYYY-MM-DD）`，至少 8 條、至少 1 條公司官方文件；分「公司文件」「媒體與研究」兩組（`### 小標`）。
    查不到兩家一致的數字，最後一行寫「資料侷限：…」。

## 寫法

- 結論先講；只寫事實與數字；不用比喻、口語、驚嘆號；一句不超過 60 字。
- 數字：資料包裡有的照抄（四捨五入可以）；網路查到的那一段要有連結；「約」可以有 3% 誤差。
- 單位：金額寫「億元」、比例寫「%」、差距寫「個百分點」、股價寫「元」、倍數寫「倍」。美股：金額寫「億美元」、股價寫「美元」；段落同台股，產業報告的「台灣成員營收與估值」改成「美股成員與估值」。
- 引用法人或媒體的看法要寫是誰、什麼時候；不寫「市場普遍認為」。
- 不寫檔名、資料包、查證過程；不寫「值得注意的是」「整體而言」「綜上所述」等填充語。
