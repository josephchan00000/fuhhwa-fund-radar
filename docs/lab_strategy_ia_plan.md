## 4. 實作方式

- **總經策略放進個股頁同一支程式（x9.html，arm/lab/page.py）**：一份頁面兩種身分——「策略」（`x9.html?v=mac`、`?v=stg`）與「個股」（`x9.html`，預設個股表）。頂欄依身分亮「策略」或「個股」，第二排只列那個身分的分頁；點頂欄另一個身分不重新載入。
  理由：個股策略的卡片、時間軸、比較表、說明卡都是這支程式的元件，總經策略要「比照」就直接沿用同一套（同一份樣式），不另外抄一份；股票名稱點了照樣在同一頁打開個股卡。另開一頁的話，要再內嵌一份約 1MB 的個股資料（股票清單、策略逐筆交易），每天的 commit 會多一倍。
- **資料**：新模組 `arm/lab/xsadvice.py` 把 xstrat 的結果整理成和個股策略同樣的形狀（每個市場一份：卡片、時間軸事件、比較表），`page.build` 內嵌（估計壓縮後多 30～50KB）；淨值與每一筆照舊放 `x9xh.json`，打開說明卡才下載。
- **JS**：時間軸（tlDraw／tlNext／tlSec）改成吃一個參數（個股策略，或某個市場的總經策略）；總經的卡片、比較表、說明卡另寫，用同一組 CSS class。
- **舊網址**：`x9x.html` 留成轉址頁（`#i=xs:市場:策略` 轉到新位置的那張卡）；`x9xh.json` 照寫（訊號總覽的面板也讀它）。景氣頁今天的重點的策略列、市場狀態那一行（10 個月均線、融資維持率）、訊號總覽的連結改到新位置。
- **用字**：頁面上的「大神策略」改叫「總經策略」（說明照舊：照書上、論文裡的規則，在五個指數上做一遍）。
- 不動：訊號總覽的判定與研究細節、各研究檔、06:35 推播、主頁。
