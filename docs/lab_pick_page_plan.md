# 選股頁改版規劃（2026-10-28）

使用者原話：「你的投資組合太不成熟了，幫我重新設計直接把配置那頁拿掉，然後把現有的選股策略做好妥善的規劃呈現出來單獨一頁，
我要分成台股跟美股，有不同策略建議進場的時程行事曆，你幫我先詳細規劃後逐步執行，本來的配置回測那些丟到研究紀錄裡面。」

要做的四件事：

1. 拿掉配置頁（兩成長抱、八成機動、警訊換現金這一整套投資組合）。
2. 新的一頁只放選股策略：分台股、美股，每條策略自己講清楚選什麼、什麼時候買、抱多久、怎麼賣、過去照做的成績、現在拿著什麼。
3. 每個市場一份進場行事曆：不同策略的名單日、買進日、賣出日放在同一張月曆上。
4. 原本配置頁的回測與交易計畫（現在的錢、今年逐月、持股、警訊、過去照做、細節、全部策略表）整個搬到研究紀錄，不刪。

### 2.2 行事曆

- **事件**（每個市場一份清單，每筆＝日期、開盤／收盤、策略、動作、股票）：
  - 名單（◆，收盤）：新飆股每週、財報驚喜每季、月營收每月、長線每月、臺灣50 選股日、美股每週五。
  - 買進（▲，開盤）：名單隔天；已知股票的寫股票名，還沒出名單的寫「新名單」。
  - 賣出（▼）：已經拿著的股票照規則的賣出日（新飆股、財報驚喜、臺灣50、月營收換股）；長線與美股強勢品質股沒有固定賣出日（停損、跌破 50 日線），
    不放在月曆上，持股表寫賣出條件；美股每天的 50 日線檢查有排定賣出時（例：10/28 開盤賣 VLO）才放。
  - 調整（●）：臺灣50 截止日隔天的換股。
  - 美股另加持股的財報日（灰色小字，已有的 Yahoo 資料；不是買賣）。
- **往後推算**：名單日與買進日照規則往後推到第 3 個月底（休市照證交所／NYSE 官方表）；已經知道的（現在的持股、已出的名單）用真的股票，
  其餘寫「新名單」。財報驚喜的賣出日也推（買進後第 60 個交易日）。
- **呈現**：月曆只排週一到週五（週末沒有事件）；一格放 2～3 個策略色塊，多的寫「＋N」；點一天，月曆下面列出那天每一筆。
  今天框起來、過去的日子變淡。策略按鈕可以關掉某條策略；預設只開主要的（台股：新飆股、財報驚喜、臺灣50、長線），其他 4 條要點「＋其他」。
  手機同一張月曆（每格只放色點＋數字），點一天看清單。
- 月曆下面「接下來 4 週」清單，每天一行（開盤在前、收盤在後）。
- 顏色：每條策略一個身分色（同一條策略在月曆、清單、卡片標題用同一個顏色），動作用符號（▲▼◆●），不是只靠顏色。

### 2.3 策略卡（每條一張）

1. 標題：策略名稱（身分色）。
2. 選什麼：一句。
3. 時程：一行規則＋下三次進場日。
4. 怎麼分錢：同時最多幾檔、每檔等額（這條策略自己那份錢；不再寫占全部資金幾 %）。
5. 現在：拿著的（股票、哪天買、買進價、現在、漲跌、預定賣出日或條件；點一列開個股卡）、待買進、下一份名單。
6. 名單：新飆股這週名單（前 20）＋位置圖、美股名單前 5 名（收起）。
7. 過去照做：一行（每次平均、賺錢比例、最差一次；全部資金照做的年化與最慘跌，旁邊同一段大盤）。
8. 風險：最多兩行（判定沒過照用、看過結果才訂的規則、次數少…；照主頁面用字）。
9. 連結：規則與逐筆成績（研究紀錄）。
