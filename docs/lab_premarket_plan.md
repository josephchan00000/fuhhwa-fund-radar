使用者 2026-11-05：「我只要你去規劃壓力線支撐 當日盤勢的各個點然後去試算風險報酬等等 參考各式指標籌碼因素期貨因素 以台灣的指數為基準去看 我每天盤前看就好」。

## 1. 要回答的四個問題（每天早上一張圖）

1. **今天大概從哪裡開？** 夜盤台指期收盤換算成加權指數（減掉日盤收盤時的期現價差），加上美股收盤（費半、台積電 ADR、VIX）當參考。
2. **今天正常會在哪個範圍裡動？** 選擇權隱含的一天波動（價平隱含波動率 × 指數 × √(1/252)；作戰表已經在算，11/4 是 ±942 點），另列 2 倍範圍（極端日）。
3. **上下最近的壓力、支撐在哪？為什麼是那裡？** 每個價位列出來源；好幾個來源擠在同一帶（共振）就標「較強」。
4. **在這些價位做，風險多少、報酬多少？** 每個情境列停損點數、目標點數、報酬／風險比，換成小台（每點 50 元）與選擇權買方（照每筆上限 2%／3%／5%）的金額。

## 2. 價位的來源（全部用加權指數為基準；期貨價位先扣掉期現價差）

| 類別 | 價位 | 資料（已經有的打 ✓） |

| 選擇權未平倉 | 最近一批（不含當天到期）買權未平倉最多的履約價＝壓力、賣權最多＝支撐；第二多；最大痛點（買方到期價值總和最小的履約價） | ✓ 資料分支日行情（全部履約價） |

**合併規則（草案，寫規格時定死）**：價位相差 0.25%（11/4 約 107 點）以內併成一帶，帶上的不同類別數＝強度（1～2 一般、≥3 較強）。
只列「預估開盤上下各 3 個」與「正常波動範圍內的全部」，太遠的（超過 2 倍正常波動）收起來。
選擇權最多未平倉常常離得很遠（11/4 最近一批買權最多在 46,500、賣權最多在 40,000，因為部位是前兩週在高檔建的），
所以分兩層：「正常波動 2 倍以內未平倉最多的」當價位，「全部最多的」只列在事實表。

## 3. 籌碼、期貨、指標（事實表；第 2 段只列事實，第 3 段驗證過才給偏多偏空）

| 類別 | 項目 | 資料 |
|---|---|---|
| 期貨籌碼 | 外資台指期淨未平倉（口）與一天變化；三大法人小台淨部位 → 散戶小台多空（＝ −法人淨部位 ÷ 小台總未平倉） | ✓ `macro_chips` tx_foreign_net、`heat/futi`、`heat/mtxoi` |
| 選擇權籌碼 | 外資買權、賣權淨部位（金額）；全市場 P/C 比（未平倉）與它在過去一年的位置 | ✓ `heat/opti`、`heat/pcr` |
| 現貨籌碼 | 三大法人買賣超（億）、融資增減 | ✓ `macro_chips`、`heat/margin` |
| 期貨因素 | 期現價差（日盤收）、夜盤漲跌、夜盤相對日盤收的跳空 | 部分 ✗（夜盤） |
| 美股與匯率 | 費半、台積電 ADR 漲跌、ADR 溢價、VIX、新台幣 | ✓ `macro_chips` |
| 技術指標 | RSI(14)、KD(9)、MACD 柱、收盤在各均線上下、布林通道位置 | ✓ 由收盤算 |

每一項寫「數字＋一句白話」，例：「外資台指期淨空 93,647 口，比前一天多空 1,835 口」。
**不先貼偏多偏空的標籤**：常見說法（外資空單多＝偏空、P/C 比高＝偏多）在台股不一定成立；第 3 段用歷史驗證，過了才標，沒過的照實寫「過去沒有比隨便猜好」。

3. **驗證（先寫規格、commit，再算）**：
   - 價位有沒有用：每種價位「碰到之後回頭」的比例，跟同樣距離的隨機價位比（打亂測試）；沒比隨機好的照實標「參考用」。
   - 碰到的機率：用 2016 年起的 5 秒指數，算「距離開盤幾倍正常波動的價位，當天碰到的比例」。
   - 每個籌碼／期貨因素：隔天開盤到收盤、收盤到收盤的方向，有沒有比隨便猜好；過了才在事實表標偏多偏空。
