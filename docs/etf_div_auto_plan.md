## 2. 決定（2026-11-01，使用者「好」照建議）

1. **不做新聞備援**：交易所兩張表涵蓋追蹤清單這個月要除息的檔；新聞標題很少有金額、也常是評論文。
2. **顯示「M/D 除息・金額待公告」**：交易所表已排好這個月的除息日、還沒有金額時。
3. **休市表**：隔年的表改自動抓證交所網站版；11 月底證交所還沒公告 2027 的表就提醒使用者（可把 12/1 的期限延到 12/20）。

## 3. 第二段：做法

- `arm/connectors/twse.fetch_exdiv`、`arm/connectors/tpex.fetch_exdiv`：抓兩張預告表 → `(代號, 除息日, 金額或 None)`；回應形狀不對就丟例外。
- `arm/etfwatch.exchange_distributions`：每檔取今天以後最早的一次；回傳兩邊是不是都抓到了。
- `etfwatch.fetch()` 預估配息的順序：etfinfo → 交易所預告表（`est_src="exch"`）→ MOPS；只收這個月、還沒過的。
  沒有金額 → `est_pend` 記除息日；交易所這輪抓不到就沿用舊的 `est_pend`（過了除息日照樣拿掉）。
- 主頁配息欄：`fund_dashboard._div_cell` 顯示「M/D 除息・金額待公告」；資料來源註記改成證交所／櫃買預告表（可點過去核對）、MOPS。
- 拿掉人工清單 `ANNOUNCED_EST` 與它的兩支測試、債務帳那一列。
- `arm/twholidays.NEXT_API`：`fetch_and_save` 抓完今年的表，再抓隔年那張；公告前 0 列＝正常；抓不到只印一行、不擋今年的。
  證交所一公告，CI 下一輪就整年取代暫代層（日誌印「證交所另加：…」）。
