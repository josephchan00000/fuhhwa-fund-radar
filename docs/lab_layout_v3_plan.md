# 籌碼雷達 版面 v3：訊號、策略頁改成「操作在前、驗證分開」（規劃，2026-10-15）

## 0. 使用者需求

原話：「排版好亂……我到底該在什麼時候買進什麼，預期持有多久報酬率多少，除了超額之外我也要知道實際報酬率多少吧，
你自己的驗證跟我沒關係應該切開來吧」「尤其針對訊號跟策略」。

讀者打開策略頁要回答的問題，依序：

1. 接下來哪一天、買哪幾檔？
2. 抱多久、哪一天賣？
3. 照做過去實際賺多少（扣成本後的報酬，不是超額）？最差一次虧多少？同期大盤漲多少？
4. 已經買的哪天賣？哪些要避開？
5. 每條策略可信度多高？（評級＋白話理由）
6. 想深入時：怎麼驗證的？→ 另一頁

## 2. 設計原則

1. 一個區塊回答一個問題，第一行就是答案。
2. 操作依日期排（行事曆）。可信度用評級標籤表示，不用排序表示。
3. 報酬先寫實際報酬（扣成本），旁邊只放一個比較：同期大盤（加權報酬指數，含息）。
   「贏同一批股票多少」「t 值」屬於驗證，放驗證頁。
4. 每個報酬數字都帶持有期與樣本（期間、次數）。資料短的直接寫「只有 3 個月資料」。
5. 共同資訊（成本、部位規則）每頁寫一次。
6. 操作頁不出現 t 值、樣本內外、穩健度、參數鄰近、因子檢定。
7. 手機優先：行事曆每一項不超過半個螢幕。

## 3. 策略頁（只放操作）

### 3.1 行事曆（頁首）

所有已知日期的動作依時間排：買進、賣出、換股都在同一條時間軸。買進項目附「過去照做」；賣出項目附持股與目前報酬。

```
10/15（四）
  開盤 買進｜共識加碼・開低進場  B・每檔 ≤ 資金 2%
  國巨 627・聯亞 2,880・臻鼎-KY 567・信驊 17,500
  條件：開盤價低於昨收才買
  賣出：10/19（一）收盤（持有 3 個交易日）；收盤跌破停損價提前賣
  過去照做（2026-07～10，39 檔）：每檔平均 +2.7%、中位 +1.5%，64% 賺錢，最差 −8.3%
  同期大盤平均 +0.7%｜每 10 萬：中位 +1,500 元、最差 −8,300 元

10/19（一）
  開盤 買進｜臺灣50 提前卡位  B
  台塑 88.9・景碩 1,050（10/16 收盤定案，名單可能變）
  賣出：12/17（四）收盤（約 2 個月）
  過去照做（2024-10～2026-07，8 次）：每次平均 +11.6%、中位 +11.9%，8 次 7 次賺，最差 −3.6%
  同期大盤平均 +6.3%
  收盤 賣出｜10/15 有買到的共識加碼

11/12（四）
  收盤 賣出｜財報驚喜（大型股，8/17 買進）
  聯電 +16.9%・台積電 +3.3%・台光電 −10.5%・文曄 +3.6%・台燿 +2.4%
```

規則：

- 已買進、還沒賣的部位只出現在「賣出」那一天，並註明「沒跟上的不追買，等下一次買進日」。
- 名單還沒產生的（月營收驚喜 11/10、財報驚喜 11/16 收盤才決定）列「名單 X/X 收盤產生」與過去照做的結果。
- C 級策略不進行事曆。

### 3.2 避開

- 高股息換股（00919、00929 12 月預估名單）：哪幾天、哪些不買、持有者哪天前賣。
- 共識加碼後隔天開高 ≥3%：不追。

### 3.3 策略一覽

| 欄 | 內容 |
|---|---|
| 策略 | 名稱、做法一句、一次持有多久 |
| 過去照做 | 期間、次數；每次平均／中位 |
| 賺錢比例、最差一次 | 報酬 >0 的比例；最差一次的報酬 |
| 同期大盤 | 同一段持有期間大盤的平均報酬 |
| 年化 | 全部資金照做的年化（有 2013 起資料的才有）與同期大盤年化 |
| 評級 | A／B／C 標籤 |

排序：可下單（A、B）在前；C 級與高股息換股（只當出場規則）在後、灰字。

### 3.4 各策略說明（每條一張卡）

1. 結論一段：實際報酬、同期大盤、最大跌幅、資料期間。例：
   「每季財報公布期限後，買進 EPS 成長最出乎意料的 5 檔大型股，持有約 3 個月。2014～2026 年照做 49 次：每次平均 +13.0%、
   中位 +6.9%，65% 賺錢，最差一次 −28.3%；同期大盤每次平均 +6.5%。全部資金照做年化 +47%（2014～2021）、+55%（2021 起），
   同期大盤 +14%、+27%；資金曾從高點跌掉一半。」
2. 怎麼做：條列規則（範圍、何時決定、選哪幾檔、何時買、何時賣、停損）。
3. 過去成績：逐年報酬表（年｜策略｜大盤）＋資金曲線（策略與大盤）；資料短的列逐筆交易。
4. 風險：白話 2～4 條（最大跌幅、成績集中在哪幾年、資料多長、有沒有停損）。
5. 「驗證細節 →」連到驗證頁的同一條策略。

### 3.5 部位怎麼算（一段）

評級對應的每檔上限、有停損時的上限、流動性、同一檔不重複加碼、注意股處置股不買。

## 4. 驗證頁（和操作分開）

入口：頂欄右側「驗證」，和「名詞」並列，不放主分頁列。內容是現有的、全部搬過去不刪：

- 評級規則（A／B／C 條件）、評級總表（選股、t 值、樣本內外、報酬型態）
- 各策略評級依據：選股、報酬型態、穩健度三項、參數鄰近、前瞻、因子檢定、資金曲線對同一批股票（含樣本內外分界）、分期
- 全部策略總表（16 版本）、低回落例外檢查、CAN SLIM 對照、沒採用的項目
- 臺灣50 三種做法比較、共識加碼持有天數比較、高股息各項測試
- 訊號成績單的算法（成本、隔天開盤進場、同一檔 5 日內只算一次）

## 5. 訊號頁

### 5.1 結論（頁首，數字每天由資料算）

10/14 的值：

> 8 種訊號照做（訊號隔天開盤買，2026-07-27 起、上漲行情）：持有 5 天實際平均 −0.3%～+1.6%，同期大盤 +0.7%～+1.8%，全部輸大盤；
> 持有 20 天實際平均 +0.8%～+6.3%，4 種平均小贏大盤，但一半以上的股票輸大盤。訊號只當觀察線索，不是買點；
> 要照做的看策略頁（共識加碼加上「開盤低於昨收才買」是 B 級策略）。

### 5.2 訊號一覽表

| 訊號 | 今天 | 持有 5 天：實際平均（賺錢比例） | 同期大盤 | 持有 20 天：實際平均（賺錢比例） | 同期大盤 | 能不能照做 |
|---|---|---|---|---|---|---|

「能不能照做」：單獨照做輸大盤／加條件後＝策略頁某策略（連結）／樣本不足。風險訊號（集體撤退）改寫「被減碼後的表現」。

### 5.3 各訊號

意思一句；照做結果一句（含「隔天開盤平均已漲 +2.65%，好處多半在開盤前就反映」這類原因）；今天名單精簡成股名＋主動 5 日淨買＋投信家數；
「全部 N 檔 →」連到個股頁篩選。

## 8. 資料層要補的欄位

- `backtest._agg`（訊號）：中位報酬、賺錢比例、同期大盤平均。
- `advice`：策略的「過去照做」補平均、同期大盤平均、期間。
- `bt3l` 研究檔重跑一次（約 3 分鐘，不改規則與評級）：每期平均、同期大盤（加權報酬指數）、年化大盤、逐年報酬（策略、大盤）、
  資金曲線加大盤。重跑後評級必須和現在相同（6 條 B、財報驚喜中型股 C；高股息換股追買 C），不同就停下來回報。

1. 資料層＋測試。
2. 策略頁（操作）＋驗證頁搬移 → 截圖。
3. 訊號頁 → 截圖。
4. 今日頁、名詞、用字 → 電腦 1280、手機 390 全頁截圖。
5. 文件、push；問是否上線（分支上已完成、尚未上線的「低回落例外」一起）。
