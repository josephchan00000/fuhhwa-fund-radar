# 大盤修正中的領導股（《超級績效》）

使用者 2026-11-21：「現在大盤崩了 你的新飆股策略應該可以找到一些潛在的飆股 你幫我把超級績效裡面的邏輯挑出來找」。

## 1. 之前做過什麼（知識庫 wiki/lab/superstock.md）
- 書的買賣法（P4.0、P5）與照書選股（W9：趨勢樣板＋RS ≥ 80＋EPS 與營收年增 25%＋加速）在台股都沒贏：W9 2019 起年化 24.3%，新飆股 43.3%、大盤 27.4%。
- 三段期間都比較準的只有價格強度（RS ≥ 90、相對強勢前 10%）。
- 規定：書的方法不再用同一批歷史資料換參數重跑；新的想法先寫規格、只靠上線後的前瞻記錄判斷。

## 2. 這次的想法
書裡說大盤修正時最抗跌、離高點最近、相對強勢還在的股票，常是下一段的領導股；大盤還在下跌趨勢先列觀察、不買新的。之前沒試過。
規格 `arm/lab/crashspec.py` VER 1（算名單之前寫定）：修正中（指數離 52 週高點 ≥ 15%）→ 抗跌（股票跌幅 ≤ 指數 × 0.5）＋ RS ≥ 90 ＋ 長期趨勢還在；
標出趨勢樣板幾條、照書三關、位置與樞紐停損；每週記下來，至少 3 次不同的修正、每次都有 126 天結果才判斷。不做歷史回測。
