# 〈台股盤前重點〉2026/09/09（週三）TST

## 🔹盤前速覽

台指期夜盤8日開低震盪，最深一度殺至**46,561點**，隨後收復失土，截至晚間8點20分報**46,902點（跌53點、跌0.1%）**，仍未站回47K關卡，追價力道保守。

昨夜美股費半終場**大漲1.30%收11,887.87點**、台積電ADR同步**勁揚2.35%收439美元**，晶圓代工與ASIC需求延續發威。惟台股8日已現獲利了結賣壓，**三大法人合計賣超125.2億元**、僅外資連3日站在買方。

盤前研判：開盤資金可能延續聚焦**記憶體與被動元件**兩大實質受惠族群，權值電子股評價偏高、賣壓風險仍須留意，屬中性觀察、非漲跌預測。

### 1. 台股8日獲利了結拉回 三大法人轉賣仅外資連3買（聯合新聞網／鉅亨網｜09/08｜【新事件】｜重要度 8/10）

1. **新聞摘要**：台股9/8終場下跌220.49點，收在**47,105.78點**。單日高低震盪達554.51點，成交量放大至**8,766.62億元**。早盤台積電攻上2,505元，一度推升指數上漲逾250點。惟盤中台積電、川湖、聯電、台達電等權值股同步走弱，漲勢收斂並翻黑。官方統計三大法人合計**賣超125.2億元**，外資連續第3個交易日站在買方，投信與自營商轉為賣方主力。
2. **一句話重點**：權值股高檔獲利了結，三大法人轉賣拖累台股由紅翻黑收跌逾220點。
3. **漲跌分析**：昨夜費半終場**大漲1.30%收11,887.87點**、台積電ADR同步**勁揚2.35%收439美元**，AI晶圓代工與ASIC需求延續強勁。台股本身卻未同步走揚、反小跌0.47%。主因先前已連日大漲至47K天量、買盤動能鈍化，加上三大法人轉為淨賣，權值股獲利了結賣壓浮現，屬短線籌碼調節，非基本面反轉。
4. **對持股／族群影響**：權值電子股（台積電、聯電、台達電）短線評價偏高、賣壓浮現機率提高。惟資金分歧明顯：**AI測試需求爆量的穎崴8月營收暴增逾兩倍**，股價亮燈漲停重返7,700元，坐穩台股第三千金。這顯示資金仍集中在具體業績佐證的次族群，非全面性拉回。
5. **對盤前市場情緒影響**：三大法人轉賣降溫短線追價信心，市場情緒轉趨觀望。後續觀察：台指期夜盤能否重返47K關卡，以及9/10台積電8月合併營收是否延續高基期成長動能。
6. **參考連結**：[三大法人轉賣超近百億元！僅外資連3買 台股震盪554點、資金轉進3族群](https://udn.com/news/story/7251/9741695)、[千金股唯二亮燈！穎崴飆漲停7,700元 探針卡三雄各搶AI測試與CPO商機](https://udn.com/news/story/7252/9740938)

### 2. 記憶體缺貨潮延燒 模組廠8月營收全線創高 威剛189億居冠、宜鼎年增576%（聯合新聞網／鉅亨網｜09/08｜【新事件】｜重要度 7/10）

1. **新聞摘要**：全球AI基礎建設投資熱度延續，上游記憶體原廠對非AI應用供給持續偏緊，帶動8月價格續揚，5大模組廠營收同步創高。**威剛8月營收189.3億元、月增近3%、年增279.81%**，寫下連6個月新高，前8月累計已突破千億元。**宜鼎8月營收86.8億元、年增576.29%**，續創歷史新高。群聯8月營收59.34億元、年增23%，同創同期新高；巨虹8月營收更暴增145%，創20個月新高。
2. **一句話重點**：記憶體供給吃緊延續，五大模組廠8月營收齊創新高紀錄。
3. **漲跌分析**：宜鼎董事長示警**記憶體價格只會走揚、供應吃緊延續至2027年底**，市場解讀為需求端支撐尚未鬆動。惟個股股價對利多**反應相對有限**，主因評價已提前墊高，市場等待更多能見度確認，並非需求疑慮所致。
4. **對持股／族群影響**：記憶體模組族群（威剛、宜鼎、群聯、巨虹）短線營收動能明確，若價格續揚趨勢不變，第三季獲利能見度可望進一步提高。上游DRAM原廠（南亞科、華邦電）同步受惠**利基型記憶體漲價循環**，供應鏈評價重估壓力有機會延續擴散。
5. **對盤前市場情緒影響**：實質營收數字佐證支撐記憶體題材信心，市場情緒偏向正向，但需留意評價已提前反映的獲利了結風險。後續觀察：南亞科、華邦電第三季法說對漲價幅度與HBM排擠效應的具體指引。
6. **參考連結**：[威剛8月營收189億元續寫新高 前8月破千億元](https://news.cnyes.com/news/id/6599269)、[記憶體缺貨潮！5大模組廠8月營收續升](https://news.nextapple.com/finance/20260908/E3D82DC51C6DD9A61C20A53ADB83FEE6)

### 3. 國巨8月營收連6個月創高 被動元件全面走揚（聯合新聞網｜09/08｜【新事件】｜重要度 7/10）

1. **新聞摘要**：國巨9/8公告**8月合併營收163.32億元、月增1.2%、年增51.8%**，連續6個月改寫單月新高，反映AI相關需求持續推升被動元件市況朝「量增價揚」發展。同日聯合新聞網報導，被動元件標準品需求同步回溫。日、韓廠MLCC高階產能排擠，台廠成為中高階容值外溢訂單受惠者，被動元件族群股價普遍走揚。
2. **一句話重點**：國巨營收連6月創高，標準品需求回溫帶動被動元件全面點火。
3. **漲跌分析**：國巨營收公布後市場解讀正向，**年增逾5成反映MLCC供需吃緊延續**，帶動被動元件族群同步走揚。此波反應主因供應鏈缺貨題材有具體營收數字佐證，屬基本面驅動的上漲，而非單純評價炒作。
4. **對持股／族群影響**：被動元件龍頭國巨營收動能可望**外溢至同族群供應鏈**（信昌電等高壓MLCC廠）。標準品需求回溫也有利中小型被動元件廠訂單能見度回升；惟評價已快速墊高，若後續營收動能不如預期，恐面臨**修正風險**。
5. **對盤前市場情緒影響**：實質營收數字強化被動元件題材信心，市場情緒偏多。後續觀察：日、韓系MLCC廠調漲價格是否如期於9月生效，以及國巨後續法說對供需缺口的具體展望。
6. **參考連結**：[被動元件產業好消息 標準品需求回來了](https://udn.com/news/story/7240/9742602)

### 4. AI供應鏈法說潮延燒 廣達今日登場、能見度看至2028（經濟日報／鉅亨網｜09/09｜【延伸】｜重要度 7/10）

1. **新聞摘要**：本週AI供應鏈三天三場法說接力登場：9/7信驊、**9/9廣達今日召開**、9/10奇鋐。範圍涵蓋AI伺服器管理晶片、整機組裝到散熱。廣達最近一次（8/13）法說會揭露，**AI伺服器占整體伺服器營收75%至80%**，全年產能將較2025年翻倍。訂單能見度已看至**2028年**，市場關注今日法說是否延續此樂觀基調。
2. **一句話重點**：廣達今日法說登場，市場緊盯能否延續產能倍增、訂單看至2028年的樂觀展望。
3. **漲跌分析**：法說會尚未召開，暫無新收盤反應可歸因。惟其上一輪法說內容公布後市場解讀正向，**產能倍增與訂單能見度延伸至2028年**被視為供應鏈景氣延續的佐證，帶動同業評價連動走升。
4. **對持股／族群影響**：AI伺服器整機組裝族群（廣達、鴻海等）若今日指引維持樂觀，可望延續信驊營收動能、對供應鏈形成正向擴散。反之若釋出保守訊號，也可能成為短線評價修正的觸發點，投資人宜逐一檢視各公司指引。
5. **對盤前市場情緒影響**：連續法說事件密集牽動盤面焦點，市場情緒預期偏向觀望等待驗證。後續觀察：今日廣達法說內容、9/10奇鋐法說，以及同日台積電8月合併營收公布。
6. **參考連結**：[廣達法說會／第1季營收、獲利創新高 AI伺服器產品迭代加速](https://money.udn.com/money/story/5612/9503176)、[廣達法說：今年產能將較2025年翻倍 AI伺服器能見度看至2028年](https://news.cnyes.com/news/id/6575714)

### 5. 台積電8月營收周四公布 市場緊盯年增率能否守住四成（中國時報／經濟日報｜09/08｜【延伸】｜重要度 7/10）

1. **新聞摘要**：台積電將於**9/10（週四）**公布8月合併營收，被視為檢視下半年AI需求與資本支出走向的關鍵風向球。市場高度關注年增率能否守住**40%**大關，藉此確認終端AI拉貨動能並未降溫。台積電**7月合併營收達4,675.8億元，月增5.6%、年增44.7%**，改寫單月歷史新高，累計前7月營收已達2.87兆元。
2. **一句話重點**：台積電8月營收明日揭曉，市場緊盯年增率能否延續守住四成大關。
3. **漲跌分析**：8月營收尚未公布，暫無新增反應可歸因。市場先行反應主要體現於昨夜**台積電ADR勁揚2.35%、費半同步大漲1.30%**，惟今日台股台積電本身盤中拉回，顯示市場對正式數字揭曉前仍保守以對，等待官方數字驗證。
4. **對持股／族群影響**：台積電8月營收若延續高基期成長，將對整體晶圓代工與AI供應鏈評價形成正向支撐。反之若年增率明顯低於40%，恐引發市場對AI資本支出降溫的疑慮，牽動先進封裝、測試、載板等下游供應鏈評價連動。
5. **對盤前市場情緒影響**：市場情緒進入等待驗證階段，短線資金可能保持觀望，避免在數字揭曉前過度追價。後續觀察：9/10台積電8月合併營收正式公布，以及蘋果同日秋季發表會對供應鏈的連動效應。
6. **參考連結**：[台積8月營收 成AI續熱風向球](https://www.chinatimes.com/newspapers/20260908000536-260110)
