## 🔹盤前卡

### 1. 台股攻上46,401點波段新高後收斂，三大法人買超643.1億元（中央社、經濟日報，2026/08/27｜【新事件】｜重要度 9/10）

1. **新聞摘要**：台股27日受輝達財報優於預期激勵，早盤開高走高，一度大漲逾569點、衝上**46,401.78點**改寫波段新高；不過尾盤高檔賣壓湧現，漲幅收斂至142.6點（+0.31%），終場收在**45,975.22點**，成交值達924.68億元。籌碼面同步轉強，三大法人合計**買超643.1億元**，其中外資買超490.9億元、自營商買超150.3億元、投信買超1.8億元；但期貨市場外資反向加碼空單，台指期（大台）淨部位擴大至**淨空84,836口**。
2. **一句話重點**：現貨買盤重回、期貨卻續空，籌碼呈現「現貨偏多、期貨偏空」的分歧訊號。
3. **漲跌分析**：大盤日內振幅逾400點，主因輝達財報財測雙優於預期，帶動費半與台積電ADR同步走高、激勵台股電子權值股全面開高；尾盤漲幅收斂則因權值股獲利了結賣壓浮現，屬多頭格局下的正常獲利了結，並非基本面轉弱訊號。
4. **對持股／族群影響**：外資現貨同步加碼電子權值與記憶體概念股，南亞科、華邦電同列外資買超前段班（詳見卡2）；融資餘額續增至5,599.2億元、融券餘額回落至210,591張，顯示散戶槓桿部位仍偏多，追價風險需留意。
5. **對盤前市場情緒影響**：台指選擇權P/C比升至105.81（前一交易日103.04），反映選擇權市場偏多氛圍續增溫；惟外資期貨空單同步擴大，顯示法人對短線高檔仍保有避險部位，市場情緒偏多但非全面樂觀。後續觀察：週五（28日）開盤能否延續攻勢站穩46,000點整數關卡、外資台指期空單是否轉為回補。
6. **參考連結**：[台積電翻黑壓盤 台股開高走低收45975點](https://www.cna.com.tw/news/afe/202608270156.aspx)、[美股早盤／輝達財報夯翻 股價飆5% 費半揚升2%](https://money.udn.com/money/story/123398/9718636)

### 2. 黃仁勳再點名記憶體瓶頸，南亞科飆逾4%領軍、MSCI季調同步加持（經濟日報、聯合新聞網，2026/08/27｜【延伸】｜重要度 8/10）

1. **新聞摘要**：輝達法說會上，執行長黃仁勳再度強調記憶體供給是當前AI擴張的最大瓶頸，帶動資金加碼記憶體供應鏈；南亞科（2408）27日盤中上漲逾4%、收541元，華邦電（2344）同步走揚，外資現貨買超南亞科、華邦電各約3萬張。加上MSCI季度調整已於8月生效，南亞科、華邦電、群聯3檔記憶體股同步納入全球標準指數，形成基本面與籌碼面的雙重催化——**新在此**：由「消息面題材延伸」升級為「法說會官方發言＋國際指數編製機構認證」雙重加持，與已報導的「DRAM缺貨看向2028年」敘事互為印證但屬新進展。
2. **一句話重點**：記憶體漲勢從產業消息延伸為法說會官方定調，催化力道明顯升級。
3. **漲跌分析**：南亞科單日漲逾4%，主因輝達財測與法說會言論再度確認記憶體供不應求的產業定調，加上外資現貨買盤集中湧入；漲勢並非單純延續前波題材炒作，而是疊加法說會官方發言與國際指數認證的雙重基本面支撐，屬於有明確觸發事件的動能延續。
4. **對持股／族群影響**：記憶體三雄（南亞科、華邦電、旺宏）與相關封測股短線同步受惠，長線供需缺口敘事因輝達官方發言而獲得強化；惟本波記憶體股累積漲幅已大，且過去一週已有陸系記憶體廠示警報價滑落風險的前例，追價須留意評價是否過熱、循環是否已進入相對高檔區間。
5. **對盤前市場情緒影響**：記憶體族群成為28日盤前資金鎖定的焦點類股之一，惟市場對「超級循環」延續時間仍存分歧，情緒偏多但非一致樂觀。後續觀察：南亞科、華邦電後續法說會或財測更新對DRAM合約價、客戶長約簽署進度的最新指引。
6. **參考連結**：[MSCI 季調出爐！台股在全球標準指數「6進6出」 記憶體3檔入列](https://money.udn.com/money/story/5607/9688383)、[輝達財報點火台股卻上演「開高收斂」 三大法人買超643億、外資加空1,182口](https://newtalk.tw/news/view/2026-08-27/1056074)

### 3. 台積電27日翻黑壓盤收2,410元，權值股表現分化透露短線疲態（中央社，2026/08/27｜【新事件】｜重要度 7/10）

1. **新聞摘要**：台積電（2330）27日早盤一度觸及2,435元，午盤後翻黑，終場小跌5元（-0.2%）收**2,410元**，成為當天壓抑指數漲幅收斂的關鍵權值股；同一交易日，鴻海、台達電等其他權值股仍收漲，顯示權值股表現出現明顯分化，並非全面性的獲利了結。
2. **一句話重點**：昨夜費半、台積電ADR皆大漲逾2%，台積電本尊卻逆勢翻黑，凸顯短線籌碼與評價的內部分歧。
3. **漲跌分析**：台積電近期股價自波段高點以來連日承壓，市場解讀主因為近期漲幅已大、法人趁高檔調節獲利了結，加上外資期貨部位同步轉向淨空（詳見卡1），現貨與期貨籌碼同步轉趨保守；反應方向明確但幅度有限——並非利空衝擊，而是評價過熱後的正常修正。
4. **對持股／族群影響**：台積電是台股權重最大個股，其短線疲弱直接壓抑大盤指數漲幅，但資金並未離開電子權值族群，而是轉向鴻海、台達電、記憶體等相對低基期或具備獨立催化的次族群，形成台股內部資金輪動，而非系統性風險訊號。
5. **對盤前市場情緒影響**：若台積電28日開盤延續偏弱格局，可能限制大盤攻堅46,000點整數關卡的力道；但考量昨夜ADR與費半皆走強，台積電補漲機率仍在，市場對其開盤走勢分歧度較高。後續觀察：28日開盤台積電能否隨ADR走勢同步反彈、外資期現貨部位是否同步轉向偏多。
6. **參考連結**：[台積電翻黑壓盤 台股開高走低收45975點](https://www.cna.com.tw/news/afe/202608270156.aspx)

### 4. 台光電除息前重挫逾6%見5,355元，25元天價股利創掛牌新高（鉅亨網、Yahoo奇摩股市，2026/08/27｜【新事件】｜重要度 7/10）

1. **新聞摘要**：ABF載板／CCL供應鏈廠台光電（2383）訂8月28日為除息交易日，每股配發現金股利**25元**、配發總額約89.6億元創掛牌以來新高，除息前夕股價劇烈震盪，27日盤中一度自前收5,960元下探**5,355元**（跌逾6%），終場收斂至約5,540元附近。此次配息來自2025年度盈餘，公司去年營收942.6億元、稅後純益146.5億元，EPS達41.67元，營收、獲利、EPS三率同步創新高。
2. **一句話重點**：除息前重挫逾6%，反映市場對高價股「除息前價差調節」的提前反應，而非基本面轉差。
3. **漲跌分析**：台光電27日盤中重挫逾6%，主因除息前部分短線與價差投資人提前出脫、鎖定除息前價差，加上高股價個股本身波動幅度較大，並非公司基本面利空；除息帶來的股本稀釋效應也讓部分投資人先行調節部位。
4. **對持股／族群影響**：台光電此次配息規模創新高，主要受惠於AI伺服器、高速交換器與資料中心需求帶動的高階CCL（銅箔基板）出貨，作為ABF載板供應鏈中游關鍵材料供應商之一，其獲利表現可視為AI伺服器供應鏈上游材料需求強度的指標，與已報導的欣興等載板廠構成同一產業鏈的不同環節、非重複事件。
5. **對盤前市場情緒影響**：28日除息後股價能否順利填息，將是觀察AI伺服器供應鏈類股評價是否過熱的重要指標之一。後續觀察：28日除息後填息速度，以及公司下一次法說會對AI伺服器訂單能見度的更新。
6. **參考連結**：[盤後速報 - 台光電(2383)下週(8月28日)除息25元，預估參考價5655.0元](https://news.cnyes.com/news/id/6583707)、[25元股利來了不想領？「這大廠」明除息卻重殺逾6％ 股價驚見5355元](https://tw.stock.yahoo.com/news/25%E5%85%83%E8%82%A1%E5%88%A9%E4%BE%86%E4%BA%86%E4%B8%8D%E6%83%B3%E9%A0%98-%E9%80%99%E5%A4%A7%E5%BB%A0-%E6%98%8E%E9%99%A4%E6%81%AF%E5%8D%BB%E9%87%8D%E6%AE%BA%E9%80%BE6-%E8%82%A1%E5%83%B9%E9%A9%9A%E8%A6%8B5355%E5%85%83-034000303.html)
