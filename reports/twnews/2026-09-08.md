# 〈台股盤前重點〉2026/09/08（週二）TST

## 🔹盤前速覽

台指期夜盤7日開高震盪，最高上探47,536點後翻黑、最低殺至47,251點，尾盤收斂於**47,280點附近（跌182點、跌0.3%）**，追價動能有限。因美股9/7逢**勞動節休市**，最近一個交易日為上週五（9/4）：**費半終場大漲3.37%**、**台積電ADR同步走揚2.85%**，主因當日非農就業新增16.2萬人優於預期，帶動AI供應鏈權值股走高，為本週台股多頭主要背景動能。

夜盤高檔震盪、追價力道收斂，資金可能延續聚焦**AI ASIC與高息ETF**兩大主軸，惟權值股評價分化已現，須留意類股輪動風險。

## 🔹盤前卡

### 1. 台股收復47K創天量 三大法人單日買超逾1,127億元（聯合新聞網／經濟日報｜09/07｜【延伸】｜重要度 9/10）

1. **新聞摘要**：台股9/7在台積電與聯發科雙引擎帶動下，終場大漲775.14點、收在47,326.27點，正式收復47K大關。成交值同步放大至逾9,300億元，創波段天量。**台積電收2,460元、上漲2.07%**。**聯發科終場暴漲7.81%收4,760元**，盤中一度觸及漲停4,855元，單檔即貢獻大盤逾200點。官方統計顯示，三大法人9/7合計買超逾1,127億元，創近期單日新高，外資、投信、自營商同步加碼。
2. **一句話重點**：聯發科攜輝達資金題材點火漲停，帶動大盤天量收復47K並創籌碼新高。
3. **漲跌分析**：聯發科單日暴漲7.81%，市場解讀為輝達8月底以35億美元認購其海外可轉換公司債的資金題材延續發酵。投資人押注**AI ASIC機櫃級布局**進入評價重估階段；台積電同步走揚2.07%，主因外資回補權值股、大盤量能回溫。
4. **對持股／族群影響**：聯發科此役帶動自身評價重估，輝達資金挹注的**AI ASIC供應鏈**（含相關封測、載板協力廠）後續可望連動走升。但同日**大立光遭外資降評重摔跌停**（詳見下卡）。這顯示資金明顯集中在少數權值題材股，呈現「指數強、廣度弱」的分化格局，非全面性慶祝行情。
5. **對盤前市場情緒影響**：三大法人單日買超創新高強化做多信心，法人圈看好台股短線挑戰更高關卡；但跌多漲少的內部結構也讓部分資金轉趨謹慎，情緒偏多但未過度亢奮。後續觀察：台積電8月合併營收將於9/10公布，是檢視AI需求熱度的下一個關鍵指標。
6. **參考連結**：[台積電攜手聯發科拉高台股！收盤上漲775點 大立光苦吞跌停](https://udn.com/news/story/7251/9739232)、[三大法人擴大買超1,138億！權值大軍奮起攻高](https://udn.com/news/story/7251/9739449)

### 2. 大立光遭外資降評重摔跌停 光學族群同步承壓（聯合新聞網｜09/07｜【新事件】｜重要度 7/10）

1. **新聞摘要**：台股同日創天量之際，**大立光股價逆勢摜破7,000元大關、摔至跌停6,660元**，走勢大出市場意外。外資報告將其評等由買進大幅下修至賣出，主因股價自今年4月以來已勁揚逾兩倍，評價偏高的疑慮浮現；報告仍正向看待其共同封裝光學（CPO）光纖陣列單元業務，但認為驗證進度尚處早期、競爭者眾多。光學同業同步走跌，跌幅普遍達半根停板。
2. **一句話重點**：外資評等急降引爆獲利了結賣壓，大立光單日重摔跌停。
3. **漲跌分析**：大立光跌停（約-10%），主因外資示警**評價已達2027年預估獲利35倍、遠高於歷史區間**，加上其**第三季累計營收僅達市場共識約53%**，短線業績動能偏弱，遭大額調節賣壓襲擊。
4. **對持股／族群影響**：光學鏡頭族群同步承壓，反映市場對CPO題材類股的**評價急漲後獲利了結**心態轉趨謹慎；投資人須留意同類高本益比題材股是否出現連動修正，惟其中長期CPO商機布局並未被外資否定，僅屬短線評價修正。
5. **對盤前市場情緒影響**：個股急殺與大盤創高同日並存，凸顯資金集中度偏高、追價風險上升，市場情緒轉趨對高評價成長股保持戒心。後續觀察：大立光8月營收公布後市場對其第三季展望的實際修正幅度。
6. **參考連結**：[大立光股價摔跌停 大出市場意外！外資指主因原來是這個](https://udn.com/news/story/7252/9739795)

### 3. 高息型台股ETF囊括11檔改寫歷史新高 00919連9天創高（工商時報｜09/08｜【新事件】｜重要度 7/10）

1. **新聞摘要**：工商時報報導，統計台股94檔ETF中，**11檔收盤創歷史新高、幾乎全由高息型霸榜**。名單包括群益台灣精選高息（00919）、元大高股息（0056）、統一台灣高息動能（00939）與元大台灣高息低波（00713）等。其中**00919已連續9個交易日改寫新高**，並甫公告第14次配息1.1元、續創配息金額新高。連續14季維持年化配息率逾10%的高配息政策，受益人數已突破408萬人。
2. **一句話重點**：台股走升帶動高息型ETF資金回流，00919連9天改寫紀錄。
3. **漲跌分析**：高息型ETF淨值同步創高，市場解讀為**台股權值股上攻帶動整體指數評價墊高**。加上高股息成分股財務結構穩健、股利具下檔保護，在波動加大環境下更受青睞，資金加速流入。
4. **對持股／族群影響**：高息型ETF規模效應可能吸引更多資金比價效應（switch）進場，對成分股中金融、傳產高股利族群形成支撐。投信法人普遍認為台股今年盈餘增速與下半年營運上修循環未變，將是高息題材延續的重要支撐，惟需留意除息旺季後淨值季節性回落的常態現象。
5. **對盤前市場情緒影響**：高息型ETF屢創新高強化存股族信心，有助分散資金過度集中於AI權值股的風險，市場情緒因資金分流而更趨穩健。後續觀察：9月除權息旺季陸續公布，各檔ETF實際配息金額是否維持年化水準。
6. **參考連結**：[11檔台股ETF創高 高息型當道](https://www.chinatimes.com/newspapers/20260908000417-260208)

### 4. 台積電8月營收周五公布成風向球 AI供應鏈本周法說潮登場（中國時報／經濟日報｜09/08｜【新事件】｜重要度 7/10）

1. **新聞摘要**：台灣AI供應鏈本週三天三場法說密集登場：**9/7信驊、9/9廣達、9/10奇鋐**。範圍涵蓋AI伺服器管理晶片、整機組裝到散熱，幾乎涵蓋AI資料中心完整供應鏈。信驊8月合併營收已率先揭曉，**達16.26億元、月增6.69%、年增118.42%，連10個月創單月新高**。累計前8月營收突破101.68億元。市場更聚焦**台積電8月合併營收將於9/10公布**，被視為檢視下半年AI需求熱度與資本支出走向的關鍵指標。
2. **一句話重點**：信驊營收連10月創高打頭陣，市場等台積電9/10營收定調AI熱度。
3. **漲跌分析**：信驊營收公布後市場解讀正向，**年增逾118%反映AI伺服器管理晶片需求持續強勁**。公司並預告第4季擬調漲售價二位數，顯示議價力仍強；台積電8月營收尚未公布，市場預期參考其7月**4,675.8億元、年增44.7%**的高基期表現。
4. **對持股／族群影響**：AI伺服器供應鏈（管理晶片、組裝、散熱）本週密集法說，若廣達、奇鋐指引同步樂觀，有望延續信驊營收動能對整體AI伺服器類股的正向擴散。反之若任一家法說釋出保守訊號，也可能成為短線族群評價修正的觸發點，投資人宜逐一檢視各公司指引而非一概而論。
5. **對盤前市場情緒影響**：連續營收與法說事件將密集牽動盤面焦點，市場情緒預期偏向觀望等待驗證，而非提前搶進。後續觀察：9/9廣達、9/10奇鋐法說內容，以及9/10台積電8月合併營收是否延續高基期成長。
6. **參考連結**：[台積8月營收 成AI續熱風向球](https://www.chinatimes.com/newspapers/20260908000536-260110)、[信驊8月營收16.26億元創新高 第4季擬漲價2位數](https://money.udn.com/money/story/11074/9735066)

5. **為什麼值得讀**：本篇跳脫單日股價漲跌，完整拆解AI供應鏈從晶片設計、記憶體到矽光子互連的三層技術演進脈絡。有助投資人理解台灣半導體供應鏈在AI浪潮中「機櫃化」的長期定位，而非僅追逐單一族群短線消息。後續觀察：南亞科、華邦電等記憶體廠商第三季法說對HBM／利基型DRAM漲價幅度的具體指引。
